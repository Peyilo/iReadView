# iBook 阴影与极限状态

2026-10-13。此修正针对 `PageTurnEffects.iBookCurl(CurlOptions)` / `curl` 入口，与新的 `pageCurl(PageCurlOptions)` 分开。

## 旧实现的问题

- 锥面阴影只有三列、两个端点，端部在非零透明度处硬切断，卷边端点容易呈现三角形或矩形色块。
- 阴影宽度由固定dp宽度乘 `height/radius` 的裁剪比值决定。真实卷起高度与radius趋零时，该比值仍可保持非零，阴影却在radius恰好为0时整体清除。
- 原始sin(π·travel)只反映控制点行程；装订约束可在行程端点之前使实际radius归零，因此该系数不足以保证此时阴影消失。
- 锥面与中央起点的圆柱使用不同绘制方法，跨中央起点时有视觉不一致风险。

## 当前算法

`IBookCurlGeometry.rimHeight` 返回投影轮廓处的真实高度；圆柱极限为radius。`IBookCurlShadow` 为两种曲面使用同一条高斯阴影带，并在有限轮廓的两端使用软圆帽。端部各保留8段采样，不让长轮廓稀释端部柔化。

令局部高度h、公开宽度参数w、投影轮廓长度L、两端柔和尺度最大值σmax：

```text
σ(h) = w·h/(h+w)
峰值系数 = shadowAlpha · sin(π·travel)
         · L/(L+2σmax) · h/(h+2·density)
横向/端部覆盖率 = exp(−0.5·归一化距离²)
```

高度衰减尺度下限为1像素。高度趋零时，σ及峰值同时趋零，不再依赖“最后一帧关闭”去隐藏固定宽度阴影。轮廓长度趋零时，长度覆盖率使阴影淡出；即使其法向因退化而不再唯一，可见强度也收敛到0。锥面趋近圆柱时，轮廓投影与高度趋近圆柱结果，阴影不再切换另一套绘制方式。

这是基于投影轮廓的连续软阴影近似，不是完整光空间遮挡解。高斯带在3σ处截断并归零，颜色仍有8位量化。没有宣称所有纸面几何、所有极值或真机性能已验收。
