# iBook 正面过渡弯曲与背面投影

## 原问题

原正面只有平面和主卷曲带；在顶视投影中，主卷曲带与更高的背面重叠，被最后绘制的背面遮挡。仅增加主卷曲段的网格密度不能产生清晰的正面过渡。原软阴影先于正面绘制，因此落在当前页正面上的部分会被正面纹理覆盖。

## 正面弯曲带

在平直正面与原圆锥/圆柱卷边之间增加一个浅 S 形过渡。沿卷边法向的材料坐标为 s，过渡材料长度 L，局部 u=(s+L)/L：

```
θ(u) = 0.65 sin(πu), u∈[0,1]
X(u) = -L + L∫₀ᵘ cos θ(v)dv
Z(u) = L∫₀ᵘ sin θ(v)dv
```

局部切线长度为1，材料长度保持；投影在中段压缩文字，两端切线水平，与平面和原主卷曲带相接。固定切线轮廓采用共享的512段中点积分表；逐顶点线性插值并按实际过渡长度缩放。过渡宽度不超过2.5倍卷曲半径，并受装订侧可用材料范围限制；半径随开始/结束进度趋零时，过渡带和高度同时趋零，不用硬切换显示。

原主卷曲表面整体增加该过渡的法向位移和高度；axis 按收缩量补偿一半，保持原圆柱反折端点轨迹。圆锥内的抓取约束仍沿用原近似，未声称所有斜角均严格抓住同一材料点。纹理坐标始终来自材料 x/y，正面不会通过旋转整张截图伪造变形。

API29+ 的 IBookCurlMesh 独立细分这段正面过渡，再连接主卷曲带；平面区裁到过渡起点。旧 bitmap mesh 路径共享同一映射，但仍受原规则网格分辨率限制。

## 当前页投影

IBookFrontShadow 从真实可见背面材料边界取样，将其按表面高度与固定斜光方向投到接收平面，在规则接收网格上计算投影边界距离，并以统一高斯衰减绘制。正面接收区域从实际变形网格建立路径，阴影被限制在正面，不染到背景或纸外。背面随后绘制，覆盖自身下面的阴影。

绘制顺序为：

1. 下层页面与卷边对下一页的投影。
2. 正面纹理（含 S 弯曲和主卷曲带）。
3. 背面边缘对当前页的软投影，裁到正面网格。
4. 背面纹理。

两种阴影共用光线斜率(0.18,0.28)、shadowAlpha、shadowWidthDp，并由高度和翻页进度连续淡入/淡出。当前页投影为有限材料边界的高度投影/高斯近似；不是逐像素光线求交或曲面接收的完整物理求解。正面 S 带部分仍可能被真实背面遮住，绘制顺序保留背面遮挡，不把所有正面强行画在背面上。

## 范围与验收

仅修改 iBook 的内部几何、网格及阴影，公共 CurlOptions 配置沿用。主题背面颜色解析继续生效；阴影资源在 finish/abort/detach 清理。正面接收路径只包含网格边界，避免逐三角形/逐网格格子创建裁剪轮廓；尚未做设备性能实测。

Debug APK、Release AAR 和发布仓库包构建通过，未添加或运行测试。设备视觉效果、不同抓取高度/RTL/极值进度、正面文字变形程度和阴影位置仍需验收。

## 2026-10-14：每帧开销优化

用户反馈加入正面过渡和阴影后卡顿。源码中发现两处新增开销：接收区域用三角形/格子轮廓集合裁剪；每个过渡顶点重复16段三角函数积分。

- 索引网格裁剪改为弯曲带外边界与平面多边形，最多两个轮廓；旧规则网格沿四条边建立单个轮廓。边界沿用实际绘制顶点，保留正面扭曲及阴影遮挡。
- 积分表按归一化切线一次生成并共享，每帧只插值、缩放；改变积分精度，几何模型不变。
- 两种阴影横向高斯权重与偏移预计算；当前页阴影索引仅在边界节点数量变化时重建。顶点位置、纸面高度、端点淡出仍每帧更新。

未降低配置网格密度或删除阴影。构建通过；未运行测试或采集设备帧耗时，实际流畅度改善仍待设备观察。

## 2026-10-14：卷边末端纹理异常

针对截图中收尖区域的扇形纹理拉伸，索引网格沿每条生成线细分为4段，避免用两端顶点组成跨越整页的长三角形。正面过渡带和主卷曲带分别建立索引，边界只共享位置、不跨带连接；零面积或非有限三角形不提交绘制。开启翻页快照的 mipmap 提示，供硬件在掠射角处选择缩小纹理，减少密集文字的采样走样。旧 Android 的规则网格路径保持原有纵向细分。

积分表、阴影缓存和边界裁剪优化继续保留。生成线细分增加几何量，限制为固定4段；mipmap 是硬件提示，实际支持依渲染器而定。构建通过，未运行设备视觉或帧耗时测试；截图异常是否完全消除仍待同一抓取位置观察。

## 2026-10-14：数学验证后的阴影修正

数学检查复现原偏移轮廓阴影的508个折叠单元。改为规则接收网格距离场，消除尖角偏移自交；新网格检查248,832个单元无折叠。纸面投影检查无翻转，上一轮细分并非本次异常的根因修复。公式、复现范围与限制见32号文档。新增并运行4项几何/阴影回归测试，设备像素输出尚未验收。
