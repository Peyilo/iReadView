# 跨页段落选区端点手柄

## 问题

长按按源段落选取完整文本，可跨页。ReaderBodyView原先只在当前分片能提供真实源端点caret时生成手柄；真实终点在下一页时返回null，当前页只有起始手柄，用户无法从当前页缩短选区。

## 行为

分页模式保留原始整段选区，在当前页选中内容的可见起点/终点补充代理手柄。若真实端点在本页，优先使用真实端点。若两端都不在本页，两端都可显示代理。没有可见选中路径的页面不凭空生成手柄。

代理从当前页实际选中分片与源选区的交集取caret，不根据整页矩形假设位置。圆点限制在View内，防止最后一行到达正文底部时终止圆点被裁没；尺寸变化后重建位置。

- 仅显示手柄不改变TextRange或quote，复制/高亮/划线仍处理完整源选区。
- 按下/轻点后松开不缩短跨页选区。超过系统touchSlop后才开始更新端点。
- 拖动代理终点向页内收缩，会将真实终点改到当前可见文字位置；代理起点同理。
- 拖到页面边缘继续使用现有延迟翻页与源锚点扩选逻辑，换页后继续跟随拖动。
- 滚动模式不在每个复用行创建代理，避免同一选区出现重复手柄。

起点上圆点、终点下圆点、选中颜色与现有公共SelectionStyle保持。

### 页面边缘手柄与文字避让

圆点的可见位置与源文字caret横坐标分开保存。只对圆点做页面边界限制，竖线仍位于真实caret，起始竖线绘制在边界左侧、终止竖线绘制在边界右侧，避免圆点内移时整根竖线压住首字。圆点与竖线横坐标不同时，在圆点高度连接；拖动偏移使用真实caret横坐标，避免视觉避让改变选取位置。无需修改公共API。

## 实现与范围

内部ReaderBodyView增加仅分页开启的showOffPageSelectionHandles，统一实际/代理caret到手柄；PagedBookPresentation增加拖动阈值判定。无新增公共API，不改变长按段落策略或跨页源文本模型。
