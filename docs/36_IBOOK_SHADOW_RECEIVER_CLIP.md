# 条形投影的接收面裁剪

截图中条形投影沿卷边延长，越过有限纸边末端进入不相关区域。修正分两层：

1. 下一页投影只在页面矩形减去当前正面与背面的实际外轮廓中绘制。使用Canvas clipOutPath，API21–25使用差集clip；复用现有外轮廓，不生成每帧Path布尔运算结果。
2. 卷边条形阴影只使用有限生成线区间[0,length]。旧圆端向区间外延长3σ，会在纸边终点后留下阴影尾巴；现在端点渐变向区间内部收敛，端点透明，保留端部采样密度。

当前页投影仍裁到正面，曲面微阴影仍使用实际纸面网格。强度/柔和度/主题颜色API不变。Debug/Release/发布包构建通过，本次未添加或运行测试；设备视觉验收尚未完成。
