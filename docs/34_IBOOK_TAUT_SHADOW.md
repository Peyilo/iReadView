# iBook 绷直纸面阴影

## 原因

卷曲半径除了翻页进度，还受装订侧可用空间限制；拖动斜度较大时，局部半径会在进度尚未结束时归零。旧阴影把 `radius<=0` 作为退出条件，同时反折平面高度也归零，因此截图中的直边纸面缺少层次。

## 调整

- 阴影不再按卷曲半径直接开关；只在翻页真正开始/完成或强度、柔和度为零时退出。
- 新增内部 `shadowHeight`，对装订约束消耗的半径增加绷直纸面抬起高度提示：

```
r0 = width*radiusFraction*sin(πtravel)
D = max(0,r0-radius)
s = max(0,n·material-axis)
H = materialHeight + 2D*s/(s+r0)*clamp(materialX/width,0,1)
```

r0为零时补偿定义为零。铰接线处s=0、材料装订边x=0没有额外抬起；受限量D趋零时补偿连续消失；进度端点r0趋零时整体趋零。保留原二维纸面几何和文字映射。

这个高度是阴影视觉近似，不能声称是满足所有抓取/装订接触约束的精确三维纸面；它明确区分局部卷曲与翻起纸面的视觉高度。

- 用同一背面边界距离场投影到下一页和当前页，取消下一页仅依赖卷边生成线的独立阴影通路。阴影只计算一次、复用两次绘制；当前页仍按正面外轮廓裁剪，背面最后覆盖其下方阴影。
- 公共shadowAlpha、shadowWidthDp、背面主题颜色API保持。
