## 2. 已落地 API 与目标设计的差异

| 设计点 | 当前代码 | 处理原则 |
|---|---|---|
| 位置存储 | 放在 `NavigationController<L>` 内，没有另建仅包一项值的 LocationStore | 保持唯一位置提交源；以后出现独立复用需求再拆分 |
| 呈现工厂 | `supportedModes`、`createPresentation(mode, host)` 装配独立呈现 | 稳定模式 ID 支持宿主子类；默认支持分页和连续滚动 |
| 模式切换 | 隐藏准备新呈现，候选包装器跟随统一导航提交；失败/取消释放候选 | 不清空已显示旧内容再开始加载；旧呈现清理异常单独报告 |
| 滚动窗口 | 最多三个章节的片段列表，边界加载失败保留正文并提供重试 | 显示窗口限制章节数量；缓存字节预算独立，单个超大章节仍需进一步优化 |
| 连续布局 | continuousFragments 与分页片段引用同一文字测量结果，保留块后间距 | 页码为虚拟分页提示；item 号不能当作章节页号 |
| 样式 | 先支持实际已绘制的字段，字体暂用运行时 Typeface | 未实现背景/字体资源表达与每层 padding 不先添加无效 setter；后续扩展保持字段单位一致 |
| 布局失效 | 样式变化保守重排，章节更新只清目标章派生布局 | 普通邻章更新保持当前章事务；绘制/排版差异优化仍待实现 |
| 线程与接口 | 协程是内部依赖；普通 Demo 使用 callback，不依赖协程类 | 库不暴露 Job/Scope；高级宿主自行使用 suspend |
| 布局单位 | 公共配置 dp/sp，测量及片段几何 px，页号从 1 开始 | 原文 offset 不通过缩进/空白改变 |
| 异步 View 等待 | 在绘制前检查有效测量，而非仅等待尺寸变化事件 | 同尺寸的重新布局也必须能完成操作 |
| 尺寸回调中的重排 | 重排工作排到本次 View.layout 之后 | 不在父级布局途中添加未经过测量的目标页 |
| 字体缩放 | 主线程通过 TypedValue 解析实际 sp 像素大小，传入布局上下文及缓存键 | 支持新版 Android 非线性字体缩放；不在工作线程读取 View |
| 回调请求 | 主线程排队启动请求，完成/取消各仅回调一次 | 监听器中发起 callback 请求在当前事件结束后执行；代次变化停止旧事件继续分发 |
| 更新回退 | 当前章锚点/页提示失效后回到本章首屏，发恢复回退事件 | 不将此回退用于普通导航；不会声称任意内容编辑都能精确恢复 |
| 重试 | 仅失败加载/布局进入重试；非当前章先重新加载内容，布局按需生成 | 不为了邻章重试强行显示邻章 |
| 目录重载 | 读取/校验与安装分开，只有明确未变的章节版本才复用缓存；无版本信息时保守重读 | 当前章变化或删除时清除旧页；重载返回目录，恢复结果由 onPositionRestored 输出 |
| 标注管理 | 独立 AnnotationStore 保存不可变纯数据；验证借用章节快照，不长期保存全文 | 宿主决定持久化格式；状态不改写原始书签/高亮，失效记录仍可导出 |
| 标注事件 | onAnnotationsChanged 输出全量快照，onAnnotationStatusChanged 输出验证状态 | 标注修订号防止监听器修改标注后继续广播旧状态；不借用阅读位置代次 |
| 高亮几何 | BlockLayoutFragment.selectionPath 返回局部坐标路径，ChapterLayout.rangesForText 拆分同章跨块范围 | 与文字绘制共用 Layout；自定义实现默认返回不支持，不伪造几何 |
| 高亮样式 | ReaderStyle.highlightStyles 使用构造时复制的 HighlightStyles，包含必需的 default 项 | 单独调整高亮颜色只刷新装饰层，StyleApplication.layoutChanged 为 false |
| 选择与工具栏 | 长按通过片段 anchorAt 命中，平台 BreakIterator 解析初始词/字符边界；ActionMode 或自定义 PopupWindow | 选区单独存储，复制仅由明确的工具栏点击触发；旧动作返回 InvalidSelection |

长按建立平台词边界归一后的初始选区，手柄可在当前页扩大到其他原文块。选择模式屏蔽普通滑动翻页，点击正文清除选区；程序跳转到别章、内容失效、目录安装和解绑会清除。字体/视口重排保留同版本的语义范围。标注 ID 默认 UUID，可替换 AnnotationIdFactory。SelectionStyle 实现 fillColor/handleColor/handleRadiusDp，仅该配置变化不重新分页。片段 caretForOffset 提供局部插入点几何，用于手柄与命中；自定义 provider 不提供几何时不显示假手柄。

拖动开始暂停工具栏动作，默认 ActionMode 不销毁，避免 API 21/22 原生栏显隐引起正文高度变化；结束后更新当前选区版本的动作。API 23+ 使用浮动 ActionMode，通过可见选区矩形定位；自定义弹窗在选区上方或下方放置，并限制在当前窗口可见区域。旧 Android 使用原生上下文栏。行尾软换行、混合 RTL、边缘手柄裁剪、复杂 emoji/字素及 API 21 词边界行为尚未在设备上验证。

跨页扩展当前采用 24dp 边缘区域与 550ms 停留间隔。PagedBookPresentation 持有跟随 attach/detach 的取消域；边缘请求通过 BookPresentationHost.requestSelectionPage 进入 Widget 的同章、代次及选区校验，然后执行无动画的 UserNavigation。只在新页面成功提交后借用其内容快照更新选区，不先改对外位置。固定端点页限制防止反向缩小范围时越过固定端点；段落间隙/缩进处的拖动命中使用 Layout 的最近可见行与合法水平范围，不逐像素搜索。普通长按仍严格命中，避免在空白区发明文字。取消导航或加载失败停止当前自动扩展；已提交的可见页面不假装回滚。跨章节选择仍不支持。

书签导航先严格定位；版本不一致时去掉版本约束重新定位同一块，块不存在时尝试同章页提示，页提示无效时定位该章首屏。返回实际 NavigationResult，并通过恢复事件输出 Exact/Fallback；章节删除仍拒绝 UnknownChapter。高亮不采用书签的近似恢复：非空版本不一致、范围/原文不匹配时明确失效，自定义非文本块当前返回 UnsupportedContent。跨段落 quote 使用单个换行分隔，逐段与快照比较，不拼装第二份完整选区文本。导入可立即验证缓存中的章节，未取得快照的章保持 PendingValidation，下一次加载时验证。

目录重载缓存判定：相同非空章节 revision 可复用；章节都没有 revision 时，只有相同非空书籍 revision 才视为未变。来源必须在内容改变时更新相应版本；版本为空不代表内容相同。目录读取期间允许普通导航，安装时捕获最新已提交位置并替代尚未完成的导航。安装后取消恢复不会撤回来源的新目录；无有效当前位置时报告可重试的 ReloadCancelled，宿主可再次重载或跳转章节。安装前取消保留旧目录与位置。
