# 条形阴影渐变纹理

针对继续出现的条纹反馈，替换下一页卷边阴影的低密度顶点颜色渐变。原17列顶点对高斯强度做分段线性插值，阴影变宽时可能露出分段斜率。新实现缓存1024×1黑色alpha渐变纹理，横向仅两列几何端点，GPU按纹理坐标与过滤采样渐变；顶点白色alpha只控制高度、进度及有限端部淡出。

保留36号接收区域裁剪、有限纸边端点和绷直高度提示；不增加模糊离屏层。渐变仅首次绘制生成，翻页结束保留复用，效果detach时清除shader并释放Bitmap。额外缓存约4KB，几何顶点从425降为50。当前页距离场与曲面遮蔽不变。

仍是8位alpha，不能保证消除所有设备上的色阶；这次消除的是粗网格对横向渐变的分段近似。尚无新的定位截图，因此不能确认所有异常条纹都来自这一通路。Debug/Release/发布包构建通过，本次未添加或运行测试，设备像素输出待验收。
