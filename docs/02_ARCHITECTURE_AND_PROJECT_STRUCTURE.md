# iReadView 架构方案与项目目录结构

> 状态：已落地的 Android View Widget 架构及后续目标；早期算法/增强描述保留，不能据此宣告验收完成。当前职责见05第2/3节，接入见08，运行证据缺口见07。本文确定组件职责、扩展边界、滚动模式处理方案和工程目录。具体 API 见 [04_WIDGET_API_DESIGN.md](04_WIDGET_API_DESIGN.md)，实现方法与包结构见 [05_WIDGET_IMPLEMENTATION_PLAN.md](05_WIDGET_IMPLEMENTATION_PLAN.md)。

## 1. 架构决策摘要

iReadView 以 **Demo App + 独立 Android View Widget 库模块** 构成一个 Gradle 工程。Library 生成 AAR及本地 Maven 仓库包，另有独立 Maven 消费示例工程；默认控件 `ReaderView` 可从 XML 或代码创建。阅读库以继承分层实现基础容器、书籍公共能力及默认呈现装配；普通分页、连续滚动是不同的内容呈现策略。字体、页眉页脚、padding、书签/高亮和翻页效果通过公开配置及数据 API 接入；宿主需要改变内容结构或展示方式时可继承/替换呈现。

当前继承链为 `FrameLayout → BaseReadView<L> → BookReadView → ReaderView`。基础容器使用泛型位置，不依赖书籍内容解析；书籍层提供标准阅读位置、内容来源与标注能力；默认控件装配可切换的分页/滚动实现。公开操作均由 Widget 暴露，内部会话与控制器由 Widget 管理。

当前核心职责链：

```text
Demo App / 宿主应用
  └─ 使用公开 API 提供书籍、章节、书签、高亮、主题及事件处理
       ↓
基础阅读容器 BaseReadView<L>（可继承）
  ├─ 阅读位置与导航边界
  ├─ 输入手势、点击区域、容器生命周期
  ├─ 翻页效果装配/切换/回退
  └─ 内容呈现扩展点
       ↓
书籍阅读层 BookReadView / 默认控件 ReaderView
       ↓
BookPresentation 内容呈现子类（决定“容器里的内容怎么展示”）
  ├─ 分页阅读呈现：一个离散阅读页、章节页码、分页锚点
  └─ 连续滚动呈现：连续内容流、跨章节接续、可见位置映射
       ↓
公共内容与标注 API / 样式配置 / 效果 API
```

翻页效果回答“内容画面如何切换”；分页或滚动呈现回答“内容如何组织、页面/视口如何生成”。这两个变化轴必须分开，否则滚动会被迫模拟普通翻页，导致状态和边界行为互相污染。

## 2. 继承层次及职责

### 2.1 基础阅读容器

基础容器是库的核心扩展基类，只实现所有阅读方式都需要的共性：

- 承载内容呈现区域，并为当前内容提供稳定的视口和输入路由。
- 接收手势/点击并转交给当前翻页效果；提供统一的上/下页、跳转和页边界语义。
- 持有并切换翻页效果，管理效果初始化、动画结束/复位/中断、尺寸变化和销毁通知。
- 维护唯一的已提交位置、导航事务和内容/位置事件边界；BookReadView 补充书籍身份与标准位置。
- 提供子类可覆写的内容创建、呈现、位置读取/定位及模式切换生命周期扩展点。
- 不负责书籍来源具体协议，不解析 TXT/EPUB/HTML，不决定章节正文 View 层级，不内置特定页眉页脚布局。

基础容器必须能在不加载正文业务实现的情况下被继承。它要清楚区分“当前阅读位置已提交”与“正在播放动画”，避免动画中间状态被当作阅读进度输出。

### 2.2 内容呈现子类

内容呈现子类决定容器内部内容的显示办法，并遵守基础容器的内容、导航和标注约定。首版至少规划两种：

- **分页呈现**：以排版参数和视口尺寸将章节映射为离散页；维护章节页数/页码、页边界和分页位置锚点；将单个页画面交给当前翻页效果展示。
- **连续滚动呈现**：将当前章节及相邻章节组织为纵向连续阅读流；维护滚动偏移、可见章节/内容锚点，按需衔接相邻章节；不把任意滚动位置伪装成分页动画的一页。

默认 ReaderView 起始采用分页，通过 `setReadingMode` 显式切换独立 `PagedBookPresentation` / `ScrollingBookPresentation` 对象。它们都实现公开 `BookPresentation` SPI，共享由 BookReadView 管理的来源、事件、样式和标注，不共享分页动画状态。宿主可继承 BookReadView，并通过 `createPresentation` 提供自己的呈现子类；无需自行装配内部协调器。

### 2.3 可配置外观和自定义页面

自定义分为三级，避免“所有定制都必须继承”或“只能配置预设”两种极端：

1. **参数定制**：字号、字体、文字颜色、背景、页面/正文/标题/页眉/页脚的 padding、行距、段距、字符间距、对齐、页眉页脚显示和内容等。调用后库负责重排并保留内容锚点。
2. **部件/委托定制**：宿主替换页眉、页脚、加载占位、页面装饰或数据绑定，但仍采用库提供的分页/滚动和导航行为。
3. **继承式内容定制**：宿主子类化阅读呈现基类，决定容器内的页面结构、绘制方式或内容组织。组件仍通过统一的书籍输入、位置、书签/高亮和事件 API 工作。

页眉/页脚配置不可与正文布局耦合：关闭页眉后，正文可用区域应扩大；自定义页眉高度变化后，应重新计算正文视口和分页，并保持阅读锚点。

## 3. 滚动模式的特别处理方案

### 3.1 决策

将连续滚动定位为 **独立内容呈现子类/呈现实现**，不作为普通翻页效果的一个动画变体。翻页效果 API 可声明对滚动呈现不适用；滚动呈现使用自己的垂直滚动交互和进度模型。

这符合职责边界：滚动模式不再有“松手后提交下一张纸或复位”的状态，也不适合前/当前/后三个离散页面的展示假设。把它伪装为翻页效果会迫使公共基类承担特殊模式分支，导致手势状态、章节加载和位置映射更复杂。

### 3.2 滚动呈现的必需行为

- 以结构化内容位置为锚点，而不是只保存像素滚动值。至少能映射到书籍、章节、内容块及块内偏移。
- 将当前章正文和相邻章片段按需接入同一纵向内容流；向前/向后预取、加载失败、重试和书首/书尾均有确定状态。
- 持续维护视口可见内容与标准阅读位置的映射。宿主查询进度、添加书签或高亮时，拿到的是内容位置而非孤立 scrollY。
- 页眉/页脚可固定在视口；正文流的分页计算仍可用于“滚动进度约等于章节页码”的显示或回到分页模式。
- 从分页进入滚动：以当前分页页首或可配置锚点定位到滚动流。
- 从滚动退出到分页：以当前视口主锚点定位到对应章节页。章节边界处按实际可见文本决定目标章节，不按旧章节状态猜测。
- 字体、视口或边距变化导致重排时，以内容锚点恢复视口；像素偏移只可作为同一布局会话中的辅助值。
- 页面效果切换和呈现模式切换是两个不同操作；若当前模式不支持所选效果，界面应标识不适用或执行明确回退，不得静默改变阅读模式。

### 3.3 滚动内容中的标注

书签和高亮锚定于内容，不锚定于 View、页码或滚动像素。连续滚动时，现有高亮随内容流呈现；长按选择返回统一章节和文本区间。分页和滚动两种呈现共享标注数据，因此切换显示方式不需要迁移标注。

## 4. 公共扩展 API 边界

本节概括调用方可依赖的能力；具体 Kotlin 类、签名、结果及生命周期契约以 04 文档为准，实现归属以 05 文档为准。

### 4.1 内容接入与接出

- 输入：书籍元数据、目录层级、稳定章节标识、章节内容块及内容版本/修订信息（如来源提供）。
- 输出：目录和章节加载状态、解析/分页失败、当前阅读位置、页面/章节位置变化、用户内容交互事件。
- 宿主可异步提供目录与章节；组件提供目标章节、预加载数量、缓存策略等可配置接入策略。
- 章节内容使用可扩展的语义块模型，不局限于默认标题/段落；具体需要支持图片块需按产品范围决策。
- 禁止要求宿主引用内部 View/Page/Renderer 对象才能读写内容或保存进度。

### 4.2 书签与高亮

- 宿主输入书签/高亮集合；组件导出当前集合或增删改变更，可供宿主自行落盘、同步或撤销。
- 书签位置和高亮范围关联稳定书籍/章节/内容锚点；不得以当前页数或当前 View 索引作为唯一持久化身份。
- 长按正文返回可校验的选择范围和所选文本快照；确认创建高亮后发出数据变更，取消则不产生标注。
- 高亮显示样式可由宿主配置；标注语义数据与显示颜色分离。
- 替换书籍、内容修订或锚点失效时，标注需隔离、报告或请求宿主处理，不能落到错误文字。

### 4.3 翻页效果 API

- 规划稳定标识的分页效果工厂，覆盖旧项目的无动画、滑动、覆盖、iBook 风格滑动、仿真卷页和 Google 风格卷页（最终清单可依产品决策调整）；连续滚动使用自己的呈现，不进入效果目录。
- 自定义效果可以接收手势起点/当前点/方向/进度、内容前后画面、视口变化，并能够响应开始、跟随、提交、复位、中止、恢复/销毁等生命周期。
- 宿主自定义效果只定义视觉过渡，页码提交和边界控制仍由阅读容器执行，避免动画插件把阅读数据改到非法位置。
- 在效果异常、不可用或呈现模式不兼容时可降级到无动画；降级不改变目标阅读位置。
- 容器拥有动画时钟与最终导航决定；效果接收只读画面、初始状态、按显示帧合并的触点变化及松手后的定时进度。静止拖动不持续调用update。每次开始最终只对应 finish（提交/复位）或 abort 之一，资源在中断/销毁时可释放。

### 4.4 导航、页码与恢复

- 稳定内容锚点是持久阅读位置，章节/全书页码是当前版式的派生数据。
- 未加载/未分页章节的页数是未知，不以 0 或加载窗口页数冒充全书总数。
- 全书页索引保留为公开能力，宿主显式请求逐章计算，可观察进度并取消；目录、正文或版式改变后失效。
- 普通导航、重排、恢复和模式切换通过同一事务提交位置；事件区分其原因。
- View 状态保存仅包含轻量位置/模式信息；来源与标注由宿主重新接入。

## 5. 目标 Gradle 工程与文件夹结构

工程位于当前项目根目录。沿用旧项目的 Gradle 组织意图：一个顶层 Demo App，阅读能力放在独立 Android Library 子模块，Demo 只依赖库的公开 API。物理目录采用和当前旧项目一致的嵌套结构：`:app` 与 `:app:ireadview`（库位于 Demo App 工程目录下）。

### 5.1 Demo 必须作为真实宿主

Demo 应从公开 API 接入示例数据源，并示范：本地文本与网络章节、恢复阅读位置、读写书签/高亮、自定义样式、定制页眉页脚、选择默认效果、自定义效果扩展、默认分页和滚动呈现。若某项只能调用库内部 API 才能完成，视为组件边界设计失败。

## 6. 目录结构对应的功能边界

| 功能面 | 负责内容 | 不应承担 |
|---|---|---|
| 公共 API | 稳定数据模型、配置入口、回调/变更输出、宿主扩展接口 | 具体数据源、持久化、页面内部状态 |
| 基础容器 | 输入、导航、阅读位置提交、效果装配与生命周期、内容宿主区域 | 书籍解析、具体正文布局、滚动章节拼接 |
| 分页呈现 | 当前章节排版、页数/页码、分页锚点、页画面供应 | 网络加载、标注持久化、效果几何细节 |
| 滚动呈现 | 连续段落流、相邻章接续、可见锚点/页码映射 | 普通翻页效果状态、数据持久化 |
| 翻页效果 | 输入进度到视觉变化的映射、复位/提交视觉、资源生命周期 | 修改书籍数据、直接保存进度、越界导航 |
| 标注 | 长按选区、书签/高亮定位和呈现 | 存储策略、书籍远端同步 |
| Demo | 示例宿主、控件展示、演示和验收入口 | 生产组件核心逻辑 |

### 6.1 工厂视图的共同所有权

页面、占位与选区工具栏统一使用内部 `ReaderViewOwnership`，在主线程按 View 实例预留未挂载候选。已挂载或已有预留的 View 不取得所有权，拒绝后不能解绑或移除原所有者的资源。组件不把预留规则公开为新的宿主接口。

| 使用方 | 预留所有者 | 释放责任 |
| --- | --- | --- |
| 分页/滚动页面 | ReaderPageTemplate 实例；ReaderPageOwnership 另保留模板身份约束 | 共享页面清理完成后释放 |
| 占位控制器 | 单次 Binding 实例 | 移除与解绑完成后释放 |
| 自定义选区工具栏 | 单次 CustomBinding 实例 | 窗口及工厂清理完成后释放 |

预留与释放都使用对象身份，释放必须匹配原所有者，旧回调不能解除新绑定的占用。一个共同 View 表覆盖不同工厂类型之间的错误复用；各控制器仍负责自己的取消、回调重入与逐项资源清理。登记仅覆盖未释放的候选和活动视图，实际生命周期及资源趋势仍需设备验收。

### 6.2 辅助阅读的原文与视图职责

`AccessibilitySourceTraversal` 在工作线程借用不可变章节快照，按粒度返回目标显示锚点和游标；明确区分章内耗尽、不支持和无效输入。它不持有 View、不加载来源、不提交位置。分页与滚动呈现负责请求归属和导航，`BodyAccessibilityHelper` 负责目标可见切片中的虚拟节点、焦点和文本事件。位置仍由统一导航控制器提交，离屏请求登记不能被当成已经移动成功。

`AccessibilityChapterTraversal` 负责按目录顺序调用既有章节读取接口、在纯定位器确认耗尽后继续下一章，并于每次挂起前后检查取消和请求归属。它逐章借用快照，不建立整书集合或布局；中间空章不提交阅读位置，找到文字或自定义块后才交还呈现处理导航。加载失败、无效或到达书边界停止。

## 8. 需要确认的产品决策

以下决策未由现有仓库确定，确认后写回需求文档：

1. 书签/高亮输入输出与选择是目标能力；范围是否允许跨段落、跨章节，草案建议允许跨段落、默认限制在单章节。
2. 图片内容是否为首版基线；完整 EPUB 版式支持仍建议单独立项。
3. 是否正式支持横屏/平板双页阅读。
4. 是否保留全部现有卷页效果，还是只保证稳定的核心效果集合。
5. 最低 Android 版本、目标设备档位、性能阈值和典型书籍规模。
6. 持久化由宿主全权负责，还是提供可选的本地存储适配器；建议默认由宿主拥有数据，组件仅提供模型和同步变更。
7. Demo 的网络示例是否需要可重复运行的本地 mock 服务/固定测试数据，避免依赖第三方站点变化。

在上述产品范围确认后，目录结构无需因某一种效果的算法而改变；效果和呈现实现可在各自职责目录内部替换。

### 来源临时文件的进程租约

TXT 索引和 EPUB 归档继续共用 OwnedSourceFile，文件创建、最后读者释放与异常终止回收由该层负责。宿主提供缓存目录，库仅在 iread-temporary-v1 子目录创建随机 .lease 标记与对应 .payload。独立标记持有进程文件锁，避免正文流关闭影响锁；进程内登记已持有的标记，回收不打开它们。文件租约不进入 Widget 泛型导航或来源公开模型。

### TXT 共用解析与存储边界

TextSnapshotParser 统一章节切分、前言/空章节、标题识别和内容标识调用顺序，通过 onBlock/onChapter 将结果交给内存模型或磁盘记录。TextLineReader 统一 BOM、跨缓冲 CRLF/CR、行尾及空白规则；TextSnapshotParser 同步累计实际输出摘要并合成快照 revision。TextContentIdentity 只负责解析期身份校验。两种存储不再各自维护章节语法和逐行处理；解析器不持有来源、View 或第二份整书模型，存储仍各自承担字节预算及资源释放。

### 内容值的指纹准备与取消职责

ChapterContent 负责不可变结构的内部指纹及已完成结果缓存；ChapterRepository 负责在线程发布前提供当前读取任务的取消检查。计算采用单个4KiB缓冲，块/批次检查，并只在成功后记忆结果。这样内容模型不依赖协程库或调度器，repository 不复制结构摘要算法；取消后未完成结果可重算，协调器/索引仍只消费字段，未新增跨层服务或公共契约。
### 内容准备与缓存记账

ChapterRepository 的私有 PreparedContent 将工作线程得到的不可变内容和估重一起交回主线程；缓存存该轻量绑定，公开查询仍解包为 ChapterContent。RetainedSize 仍是共享内部算法，工作准备/分页估算分别传入任务取消检查。主线程仅按捕获权重接纳/淘汰，避免发布时重新扫描正文；不把预算记账添加到公共内容状态，不持有工作协程回调。
### 不可变目录与索引查找

稳定章节身份的查找表属于 BookDescriptor/BookPageIndex 快照内部，不在协调器另维护可漂移副本。目录映射复用既有描述，完整索引映射保存序号，构造同时验证唯一性；新快照自然取得新映射。读者查询复用快照查找与既有前缀页数，未知/修订失配仍保留，缓存预算不承诺覆盖目录元数据。
### 章节快照共享块 ID 查找

ChapterContent 在构造时建立私有 blockId→序号映射，沿原列表顺序验证空白/重复ID；internal blockForId/blockIndexForId 为默认布局、选择、标注和辅助来源遍历共用。未知ID分别返回null/-1，原拒绝/失效原因与跨块遍历顺序保持。索引只引用已有ID与序号，随不可变章节快照释放；不引入公共查询/模型状态或独立查找服务，自定义块仍须遵守身份不可变契约。

RetainedSize 的每块结构开销从8增加到72字节，覆盖列表引用与查找表条目/槽/整数估算；内容缓存和布局估重均复用该规则。更大章节可能更早超预算而不接纳，显示工作集仍不等于缓存预算。构造索引仍为同步线性工作，内置来源在工作线程构造；字符分割/范围遍历/长块页条目仍可能线性，不把ID查找的平均常数时间当作整体延迟通过。

Debug/Java/Release构建通过，未新增或运行测试。空白/重复/未知ID、大量块下的选择/标注/辅助定位、内容更新映射和资源趋势仍需实际证据。本项替代前轮“源块查找仍线性”的默认路径说明，其他线性工作限制保留。

### TXT 可选持久索引复用

TextBookOptions新增reuseDiskIndex（默认false）与persistentIndexCacheBytes（默认256MiB，正值）；开启复用必须配置indexDirectory。默认流程不查询策略缓存键、不创建持久缓存。开启时先将一次输入流完整有界复制到原有临时租约文件并摘要，未命中从该固定输入解析，不再次打开宿主来源。缓存命中依据原字节SHA-256、bookId/书名/前言、charset名称、规范化、标题regex/flags、ID策略与格式/解析版本，以及Android构建指纹/API/runtime版本；输入超过maxInputBytes仍失败。

TextContentIdProvider.persistentIndexKey默认null；自定义策略只有显式提供非空白、覆盖全部输出语义/设置的稳定版本键才复用，命中不调用生成ID的回调。未提供键或非系统注册实现的自定义Charset沿普通重建路径。宿主必须在策略行为改变时更新键；对象身份不能证明跨进程一致。正文revision仍由原始输入与解析输出v2产生，不把缓存键替代公开内容版本。

PersistentTextIndexCache只处理来源内部的可丢弃加速数据，不进入Widget：独立iread-text-index-v2子目录、同进程登记与跨进程非阻塞独占目录锁，忙时不等待而重建。命中在短期锁内复制到来源私有OwnedSourceFile，随后验证目录及所有章的确切记录摘要；损坏尝试删除缓存并重建，来源仍按原规则关闭私有副本。缓存本身在来源关闭后保留，无活动来源借用共享payload；这替代了此前拟议的长期共享payload租约，省去新增共享读者状态机，代价是复制IO与额外临时磁盘占用。

发布先写独立.pending、同步内容，再在同目录锁内rename至最终条目；未完成文件不作为命中，下一次持锁操作尝试清理遗留pending。按访问时间淘汰，保留总最终条目字节受persistentIndexCacheBytes约束，最多128条；删除失败无法腾出空间时跳过缓存操作/发布，原加载继续。多来源共享目录时，各次操作按调用方预算尝试淘汰。扫描/复制/摘要逐批检查取消，IO/Security缓存失败仅日志并回到重建；取消和致命错误不吞掉。同步IO、目录列举/排序不保证抢占。

maxIndexBytes约束单个完整索引（包括目录/尾部），持久预算只约束保留索引条目；原始临时输入、活动私有快照、构建文件、宿主数据及OS缓存另计，不等于磁盘/内存总峰值。缓存全章摘要扫描仍为线性IO，避开解析/ID回调与逐行索引重写，不承诺每本书更快。只支持库管理的私有目录，不提供宿主编辑该格式的接口，也没有对外真实性签名。

TXT配置Demo新增索引复用选项与Bundle恢复，内存模式保留选择但不启用；内容ID样例提供明确算法版本键。界面只显示允许复用，不声称命中次数。Debug/Java/Release构建通过，未新增或运行测试；跨进程命中、输入/配置/策略更新、损坏/取消/锁竞争、预算/遗留回收及真实资源/速度仍需运行证据，不能据此认定增强项验收完成。

### 自定义原文的统一契约（2026-10-07）

api.model.TextContentBlock继承ContentBlock并声明不可变text。TextBlock/HeadingBlock实现它；宿主可附加自己的不可变元数据，无需复制库内选择/导航服务。默认文本提供者支持该接口，宿主注册提供者优先；仅HeadingBlock使用内置标题样式，其他文本块默认正文样式。分页锚点校验、选区提取/匹配、标注校验和辅助来源遍历共用此原文契约，所有偏移对应同一UTF-16字符串。

图形的说明仍属于ContentBlock/片段无障碍描述，不能借文本接口伪造可选择原文。自定义布局须把片段范围、命中、插入点、选区几何和辅助来源范围映射到text；局部描述不自动等于完整原文映射。自定义文本附加元数据不纳入内置内容指纹，宿主须更新章节revision和布局提供者version；未知持有大小仍不进入缓存。


### 辅助可见文本与原文匹配（2026-10-07）

正文辅助节点的来源范围通过当前呈现绑定的纯校验函数核对：TextSelectionResolver.matchesBlockRange按blockId取得TextContentBlock，确认范围长度/字符边界及原文regionMatches。分页与滚动共用同一函数，不复制可见子串、不增加数据源读取或导航提交。ReaderBodyView在解绑时清除校验回调；仅当前候选/代次的绑定提供原文映射，滚动另确认行仍属于列表。

不匹配的描述可继续局部朗读，但不能提供原文选择/扩展或Source离屏边界；原有无来源的视口移动/整块描述规则仍适用。校验不依赖导航busy状态，使等待离屏导航时的原焦点有效性检查仍可使用原绑定。


### 连续章节累计坐标（2026-10-07）

ScrollingBookPresentation.Chapter以DoubleArray保存取整后行高度的累计起点；章节累计偏移/高度、定位和可见位置沿Double传递，片段内绘制/命中仍用公开Float px。锚点offsetFor直接复用starts，不再独立重复累加。表属于当前滚动候选的工作集，随候选释放，不是新的全书布局缓存；每项由4字节变8字节，预算仍不等于整个显示工作集上限。


### 连续行按章节分段（2026-10-07）

默认滚动Chapter在工作准备期创建稳定的只读Row.Text/Empty列表，行引用所属Chapter。候选RowSegments仅组合保留章节列表与两端边界，不在主线程flatten全部行；通过少量分段起点实现List随机访问。seek按章节列表身份得到段起点，加章内chunk序号，不再扫描整行表。绑定归属仍核对holder位置和同一Row实例，章节/候选释放后行与数值表一并回收。

### 仿真几何与页装饰职责（2026-10-08）

两种公开仿真家族仍为Apple/iBook与Google。SnapshotCurlEffect管理两张预算快照与生命周期；GoogleCurlGeometry仅计算参考波形和随幅度调整的可见行程，EdgeCurlEffect把材料点转为网格、处理RTL与阴影。几何不持有页面、输入时钟或阅读位置。内置CornerCurlEffect保持用户要求的回退版；Demo候选不是第三种库内家族。
