# 下一页投影与曲面微阴影

## 下一页投影回归

34号修改将下一页原有卷边生成线投影替换为背面完整边界距离场。边界投影与卷边接触区域并不等价，绘制正面和背面后，下一页的部分投影可能完全被覆盖。因此恢复独立卷边轮廓投影；当前页继续使用防自交的背面边界距离场。

两种投影共享 IBookShadowLight 光向、软渐变、shadowAlpha/shadowWidthDp；接收区域和边界来源各自决定。下一页先绘制投影，正面纹理遮住不属于下一页的部分；当前页投影裁到正面后绘制，背面最后覆盖。这避免把某一种投影场当作两个接收面的完整替代。

下一页通路移除局部半径为零的硬退出条件。shadowRimHeight 在铰接线后一个请求半径处取绷直高度补偿，与原卷边高度组合，保留连续淡出和装订侧限制。

## 曲面微阴影

在实际纸面顶点上计算低强度的局部遮蔽提示：

```
coverage = radius/(radius + pageWidth*0.0025)
主卷边: O = sin²(beta)*coverage*sin(πtravel)
正面过渡: O = 0.5*sin²(πu)*coverage*sin(πtravel)
alpha = 0.2*shadowAlpha*O
```

平面区为零；局部半径与动画端点趋零时连续消失。默认shadowAlpha=0.35时最大约7%黑色覆盖，过渡带约为其一半。使用独立顶点颜色覆盖层，在每个面纹理绘制后绘制；背面颜色滤镜不会将这层微阴影冲淡。两条 Android 渲染路径都支持，复用已有纸面几何/索引，旧规则网格按卷曲带单元覆盖度衰减，避免低分辨率末端残留暗块。

这层表现是局部环境遮蔽近似，不是曲面自遮挡的光线求交。shadowAlpha=0关闭该覆盖层；不添加新的公共配置或Demo控件。
