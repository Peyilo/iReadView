# 产品范围

iReadView 是 Android View 阅读组件。宿主提供书籍、网络及文件授权、应用界面和持久化；库负责正文呈现、导航事务和阅读交互。

## 统一入口

TXT、EPUB、网络小说及未来格式统一通过 `ReaderView.openBook(BookSource)` 接入。输入位置与格式分离：网络传输不构成新的正文格式，EPUB 不需要独立 Activity。应用与库的最低 Android 版本为 API 21。

## 功能要求

| 领域 | 要求 |
| --- | --- |
| 来源 | 稳定书籍/章节/块身份与 revision，目录和按需加载，可取消并发读取 |
| 呈现 | 分页、连续滚动、模式切换；正文后端可替换 |
| 内容 | 文字、图片、正文链接和自定义内容块；原书 EPUB 使用文档引擎 |
| 导航 | 前后页、章节、源锚点/文档位置、目录与书内链接；全书页索引显式构建 |
| 样式 | 字体、颜色、字距、行段距、缩进、页面边距和正文区域 |
| 模板 | 默认六位置页眉页脚；保留任意 View 的底层扩展 |
| 选择 | 长按选段、选中高亮恢复、同章跨页拖动、统一手柄/背景/菜单与复制 |
| 标注 | 书签、高亮、划线的导入、导出、定位及版本核验；宿主负责存储 |
| 效果 | 无动画、滑动、覆盖、视差滑动、iOSCurl、GoogleCurl 与宿主效果 |
| 扩展 | 正文绘制、选区、划线、内容排版、资源读取、呈现后端和翻页效果可替换 |
| 生命周期 | 关闭、取消、替代、暂时 detach 和永久 release 的资源归属明确 |

## 核心不变量

- 阅读位置只有一个提交入口；准备候选页和播放动画不提前改变已提交位置。
- 持久位置使用来源身份与原文锚点或文档定位，不依赖版式页码。
- 原文、绘制、命中、选区、辅助访问与标注使用相同来源；不为排版改写可选择文本。
- 迟到回调及旧内容不得覆盖新会话。失败、取消、配置替代和释放均结束对应资源租约。
- 动画立即响应已识别手势；性能优化区分准备、更新和绘制，不通过缩短动画时长掩盖卡顿。
- 正文、效果、来源、业务 UI 和持久化分层；第三方实现通过公开 API/SPI 接入。

## 验证维度

功能回归覆盖文本/EPUB、分页/滚动、提交/取消、前后翻、RTL/纵向、样式与视口变化、来源切换和恢复。兼容验证另覆盖 Android/WebView 版本、复杂 EPUB、Unicode、无障碍输入和资源预算。

当前限制见[兼容边界](compatibility.md)。产品要求不是设备验收结论；持续集成只声明实际执行的检查。
