# iBook 卷边扇形异常：数学验证与修正

## 结论

上一次“增加纸面细分”的处理没有找到根因。对实际 Kotlin 几何与网格运行检查后，纸面投影在采样范围内未发生翻转；旧当前页阴影网格则能重复产生折叠单元。修正的是阴影轮廓扩张算法，不能仅靠继续增加纸面三角形解决。

## 纸面投影检查

正交投影 P(x,y) 的 Jacobian 行列式应等于朝向屏幕的法线分量：

```
J = det(∂P/∂(x,y))
平面正面: J = 1
S 形过渡: J = cos(0.65 sin(πu)) > 0
圆柱卷曲: J = cos(β)
圆锥卷曲: J = sin²α + cos²α cos(β), β=φ/sinα
圆锥反折平面: J = -cos(2α)
```

可见边界 J=0 是正常的掠射投影；前后两个可见面分别应保持 J≥0、J≤0。测试比较源材料三角形与屏幕三角形的有向面积比，另外在源材料重心处比较真实投影与三角形线性插值。有限差分检查使用0.1像素步长。

## 原阴影为什么会交叉

原阴影采用沿背面投影轮廓的偏移带。令 c(s) 为按弧长参数化的轮廓、n(s) 为单位法线、κ(s) 为曲率、σ(s) 为柔和宽度：

```
R(s,q) = c(s) + q σ(s) n(s), q∈[-3,3]
∂R/∂s = (1-q σκ)t + q σ' n
∂R/∂q = σ n
J_R = σ(1-q σκ) det(t,n)
```

当 q σκ>1，偏移带局部翻转；尖角没有有限曲率半径，固定宽度扩张必然需要处理连接。原实现仅用前后点估计法线，将偏移顶点直接连成三角形，没有裁掉自交区域。同一个四边形两块三角形的有向面积出现相反符号，形成交叉覆盖和扇形条纹。增加采样不会解除这个条件。

## 修正：在接收面采样距离场

保留背面投影边界 c_i 和每个端点高度 z_i。对每个接收网格点 X，计算到有限线段的距离：

```
v_i = c_(i+1)-c_i
t_i = clamp(dot(X-c_i,v_i)/dot(v_i,v_i),0,1)
d_i = |X-c_i-t_i v_i|
z_i(X) = lerp(z_i,z_(i+1),t_i)
σ_i = softness*z_i/(z_i+softness)
G(q) = max(0,(exp(-q²/2)-exp(-9/2))/(1-exp(-9/2)))
A(X) = max_i(strength*sin(πtravel)*z_i/(z_i+heightFade)
             *σ_i/(σ_i+cellSize/2)*G(d_i/σ_i))
```

零长度线段按点处理。高度/宽度为零时贡献为零。G 在3σ边界连续为零；max 合并避免相邻边叠加产生额外黑线。两种阴影共享光向、强度/宽度选项和 G；当前页阴影仍裁到实际正面接收区域并由背面覆盖。

网格是轴对齐矩形，每个四边形两个三角形的有向面积均为 ΔxΔy>0，因此结构上不可能因轮廓尖角出现偏移网格翻转。采用48×96单元，缓存拓扑、渐变表和数组；线段包围盒提前排除无贡献点，不引入离屏模糊层。
