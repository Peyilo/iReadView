# iReadView 阅读组件功能需求基线

> 本文保留原始FR编号、行为目标和验收场景，不等于当前实现状态。当前状态见[状态与验证](07_REQUIREMENT_IMPLEMENTATION_AUDIT.md)，新对话先读[交接说明](03_IMPLEMENTATION_HANDOFF.md)。

> 用途：为 iReadView 新项目的重新设计和实现提供可验证的产品行为基线。本文描述组件边界、对外输入输出、读者功能、扩展能力、边界行为和质量要求，不规定代码实现。
>
> 范围依据：旧参考工作区的阅读器库、示例 App、README、演示界面和现有测试。旧实现中明确存在的能力写为“基线功能”；README TODO、仅实验页面展示的能力或尚未实现完整的能力单独标注。当前项目已开始 Widget 与默认分页实现，实际范围及验证记录见 [当前状态与验证](07_REQUIREMENT_IMPLEMENTATION_AUDIT.md)，不能把旧项目证据当作新项目已交付功能。

## 1. 产品目标

提供一个可嵌入 Android 应用的阅读组件。组件是项目的核心产品，示例 App 仅用于展示接入、验证功能和演示自定义。组件需通过明确的接入/导出 API 与宿主交换章节内容、书签、高亮、阅读位置及事件；提供丰富的默认外观设置和翻页效果；并允许宿主定制阅读页内容和翻页效果。新实现需保持本文件定义的功能，同时改善性能、资源使用、状态一致性和边界清晰度。

已确定交付形态为 **Android View Widget 库**：宿主能在 XML 或代码中创建并嵌入阅读控件，用其公开方法接入内容与功能。组件遵守 Android View 的测量、布局、输入和生命周期约定，不要求宿主接入库提供的 Activity/Fragment 或自行装配内部控制器。具体类/API 草案见 [04_WIDGET_API_DESIGN.md](04_WIDGET_API_DESIGN.md)，实现方法见 [当前架构与职责](02_ARCHITECTURE_AND_PROJECT_STRUCTURE.md)。

### 1.1 目标用户和使用方

- **终端读者**：打开书籍、阅读章节、翻页或滚动、跳转章节、调整阅读外观。
- **集成应用开发者**：接入组件，提供本地或网络书籍数据，响应阅读状态，定制阅读页和加载页。
- **示例 App 使用者**：从演示入口体验阅读组件、选择本地文件、测试网络加载、观察翻页和排版效果。

### 1.2 产品边界

- 本项目是可嵌入阅读组件及其 Demo，不是完整书城；不负责书籍发现、购买、账号、云书架或跨设备同步。
- 网络内容由宿主或数据加载适配方提供。示例网络站点仅用于展示数据接入能力，不构成稳定服务承诺。
- 阅读组件负责将已提供的结构化章节内容排版显示；不承诺完整 HTML/CSS 或完整 EPUB 版式复刻。
- iReadView 目标功能必须提供书签和高亮的导入/导出 API；是否由组件内置持久化由宿主决定。阅读历史/进度需可读取并可由宿主保存。笔记功能未纳入本轮基线。

### 1.3 核心产品原则

1. **组件优先**：Demo 只能通过公开接入面使用组件，不能依赖组件内部实现细节。
2. **数据由宿主管理**：章节、书签、高亮的规范化数据由宿主提供和接收；组件提供适配、展示、交互、定位与变更事件，不暗中占有宿主数据或强制使用某种存储。
3. **默认可用，也可深度定制**：常见字体、排版、页眉页脚、背景、翻页模式和选词高亮由组件提供设置入口；内容绘制及效果实现可由宿主扩展。
4. **继承负责功能分离**：基类负责阅读容器和翻页效果的共性行为；阅读子类负责容器内页面/连续内容的呈现方式。基类不捆绑某一种书籍内容模型或页面模板。
5. **效果与呈现解耦**：翻页效果描述视图/画面的切换体验；分页和连续滚动描述内容如何组织与显示。滚动模式是特殊内容呈现，不强行伪装成普通逐页翻转。

## 2. 术语与阅读位置

- **书籍**：有标题和目录的阅读内容，可含直接章节或卷。
- **卷**：目录中的分组，可包含多个章节。
- **章节**：目录中的最小阅读单元，含标题和段落内容。
- **章节页**：根据阅读视口及排版设置，把一个章节排版后得到的页。
- **阅读位置**：分页模式下由章节序号和章节页序号共同确定；滚动模式下由可见内容在章节中的位置确定。
- **分页模式**：一次显示一个完整阅读页，通过水平/垂直手势、点击区域或程序命令切换。
- **连续滚动模式**：正文区域纵向连续显示当前及相邻章节，页眉/页脚固定。
- **翻页效果**：分页模式下页面切换的视觉表现，如无动画、滑动、覆盖或仿真卷页。

所有对外显示的书籍章节号、章节页号和全书页号均从 1 开始。无效位置不得造成越界崩溃或静默跳到无关内容。

## 3. 端到端使用场景

### 3.0 组件继承与内容呈现职责

**FR-EXT-01 基础容器职责**：组件基础类型负责可复用的阅读容器能力：接收/分发触摸与点击、容纳当前呈现所需的页面内容、维护导航边界与阅读位置、装载/切换翻页效果、转发生命周期和位置事件。它不规定某本书的章节内容如何转换成页面，也不强制使用默认的阅读页布局。

**FR-EXT-02 子类呈现职责**：宿主可通过继承阅读组件的呈现基类，决定容器内部如何构建、绑定和更新内容。子类可使用默认分页呈现，也可以实现连续滚动或其他内容组织方式。子类仍可使用统一的书籍/位置/标注数据交换和导航约定。

**FR-EXT-03 组合式外观自定义**：常见自定义（字体、字号、颜色、背景、页眉页脚、padding、间距、翻页效果参数）应优先通过配置/API完成；只有需要改变页面结构或内容组织时才要求继承/替换呈现方式。支持宿主提供自定义页面部件或绑定委托。

**FR-EXT-04 特殊呈现方式**：连续滚动不是普通“当前页/下一页”动画。它可由专门的阅读子类处理跨章节拼接、可见内容锚定和滚动位置映射，但必须遵守共同的内容输入输出、导航、书签/高亮定位和生命周期约定。

### 3.1 打开一本书

1. 宿主提供书籍加载来源以及可选的初始章节和章节页。
2. 阅读器初始化目录，并报告目录初始化成功或失败。
3. 阅读器加载初始章节及配置要求的邻近章节，解析章节内容并按当前阅读区域和样式分页。
4. 准备完成后显示请求位置；若起始位置无效，使用明确且稳定的回退位置（默认第一章第一页），同时返回可观察的失败/回退状态。
5. 加载期间显示可替换的目录加载页、章节加载页或错误页；不得把空白画面误表示为阅读完成。

### 3.2 阅读与翻页

读者通过拖动、点击区域或宿主命令翻页。阅读位置仅在一次翻页被接受时切换；动画被取消或复位时，最终位置仍为原页。越过书籍首尾时不改变位置，并以无动画/无页面跳变方式处理。

### 3.3 调整样式

读者或宿主更改主题、背景、字体或排版后，阅读器重新适配页面。调整完成后尽量保持同一段/同一阅读位置可见；若精确恢复不可行，应回退到该章节内最接近的有效位置，而不是无提示跳回书首。

### 3.4 切换分页和滚动

从分页切换到滚动时，以当前阅读位置作为滚动起点。滚动时改变章节后，返回分页模式应定位到滚动视口中当前可见的章节和页，而不是切换前的旧页。相邻章节加载中或失败时，应显示对应状态并允许重试。

## 4. 功能需求

### 4.1 书籍目录与内容来源

**FR-BOOK-01 目录结构**：支持书名、章节标题和章节顺序；目录可由章节组成，也可由卷及其章节组成。目录中章节顺序应稳定，导航和章节数计算应一致。

**FR-BOOK-02 来源适配**：宿主可接入本地或远程来源。来源至少能提供目录元数据，并按需提供指定章节内容。阅读器不要求把整本远程书籍一次性下载到内存。

**FR-BOOK-03 内置文本来源**：支持 UTF-8 等由来源指定的文本编码；允许使用章节标题匹配规则切分章节。若无标题或文件首段未匹配标题，仍须能显示内容，不得丢弃开头正文。支持从文件、输入流或应用资源打开文本。

**FR-BOOK-04 轻量 EPUB 提取**：旧工作区包含 EPUB 目录读取和正文段落文本提取能力，但仅提取部分文本结构，不是完整 EPUB 排版支持。重做版本的基线是保留“可读取目录和提取正文文本”的能力；图片、样式、脚注、复杂导航和固定版式的完整支持属于待定增强项。

**FR-BOOK-05 章节加载状态**：章节可处于未加载、加载中、已加载、加载失败等用户可感知状态。重复请求同一章节不得产生重复内容或互相覆盖的错误状态。失败后提供重试机会。

**FR-BOOK-06 预加载**：宿主可配置当前章之前和之后预加载的章节数量。预加载失败不应阻止当前已加载章节阅读；滚动连续阅读时，接近边界应按需准备相邻章节。

**FR-BOOK-07 内容解析**：支持章节标题和多个文本段落的结构化呈现；解析后顺序与来源顺序一致。内部存在图片内容类型，但默认解析链路当前主要生成标题和段落，不能据此宣称图片阅读已完整支持。首版重做需明确图片内容是否纳入基线，见第 10 节决策项。

**FR-BOOK-08 双向内容 API**：宿主能向组件提供书籍元数据、目录、章节内容及内容标识；组件能向宿主输出当前阅读位置、目录/章节/分页状态、加载错误及内容交互结果。输入模型不得要求宿主使用组件内部页面对象。

**FR-BOOK-09 更新与失效**：宿主能通知组件章节内容或目录发生更新。组件在更新后使相关页面和派生分页失效，重新显示有效内容，并保持尽可能接近旧位置的内容锚点。更新中的过期异步结果不得覆盖新数据。

### 4.2 阅读视图和页面结构

**FR-VIEW-01 阅读页布局**：阅读页包含正文区域、可选页眉和可选页脚。默认页眉显示章节标题，默认页脚显示章节内页码/总页数及时间信息；宿主可替换或定制阅读页。

**FR-VIEW-02 加载和错误占位**：目录初始化、章节加载/分页期间显示对应占位状态。错误信息应让用户能够区分目录失败、章节失败等问题，并允许可恢复错误重试。

**FR-VIEW-03 内容绘制扩展**：宿主可自定义章节读取页及目录/章节加载占位页的外观和数据绑定。自定义页面应继续具备阅读所需的正文承载能力。

**FR-VIEW-04 显示尺寸变化**：旋转、窗口尺寸变化或可用视口变化后，页面重新适配新空间，更新分页结果，并保留尽可能接近原内容锚点的阅读位置。

### 4.3 阅读导航

**FR-NAV-01 分页导航**：支持获取页数和当前页，跳转到指定页、首页、末页、上一页、下一页。跳转结果应报告成功与否。

**FR-NAV-02 书籍导航**：支持获取章节数、当前章节、当前章节页数/页码和章节标题；跳转到指定章节及章节内页、章节首页、前一章和后一章。

**FR-NAV-03 全书页导航**：当前组件公开全容器页数与当前页索引，可对当前展平后的页集合按序导航。重做时应维持全书页与章节内页定位之间的一致映射；若新方案不再提供全书连续页码，须作为公开兼容性变更单独决策。

**FR-NAV-04 页边界**：第一页不能继续向前，末页不能继续向后。章节边界上的正常翻页应进入相邻章节；全书边界应保持当前位置。空目录和空章节应显示明确空状态且保持导航安全。

**FR-NAV-05 位置回调**：页或章节位置变化时通知宿主，包含旧位置和新位置。纯动画进度、取消动画、样式重排不应伪装成用户阅读位置变化。

**FR-NAV-06 阅读位置初始化**：打开书籍时可指定初始章节及章节页；未指定时默认从书首开始。

**FR-NAV-07 进度数据交换**：宿主可读取标准化阅读位置并将其保存；重新打开时可传回位置恢复。位置至少能指向书籍、章节和稳定的内容锚点；纯章节页码在字体/屏幕变化后可能失效，因此恢复应优先使用内容锚点，再回退至章节页。

### 4.3.1 书签与高亮数据 API

**FR-MARK-01 书签读入**：打开会话时宿主可提供书签集合。书签应关联稳定的书籍标识和内容位置；在重新分页后仍可定位到原内容附近。

**FR-MARK-02 书签交互**：读者可在当前内容位置添加、查看和删除书签。组件将新增、删除及必要的位置变更以事件/数据变更输出给宿主；宿主可选择立即保存或稍后批量保存。

**FR-MARK-03 书签访问**：宿主可读取当前书籍书签集合，并可要求组件跳转到指定书签。书签失效、所属书籍不匹配或内容被删除时，应返回可处理的失败结果，不得跳到错误位置。

**FR-MARK-04 高亮读入/导出**：宿主可向组件提供高亮记录；组件可导出当前集合和高亮新增、修改、删除事件。组件不得假设高亮必须存放在本地。

**FR-MARK-05 长按选区**：正文长按进入文本选择；读者可调整选区起止位置。选择结果包含书籍、章节、稳定内容锚点/区间及所选文本快照，宿主可据此创建高亮或取消选择。

**FR-MARK-06 高亮呈现和管理**：高亮覆盖正文对应的字符区间；支持读者通过选择文本创建高亮、查看已有高亮、删除高亮。至少支持一种默认颜色，并允许设置颜色/样式。高亮的语义位置与视觉样式分离，重新分页、字体变化或视口变化后仍尽可能落在同一文本区间。

**FR-MARK-07 跨章节和文本变更**：选择/高亮范围必须有明确定义的边界规则。范围跨段落应连续覆盖；跨章节支持与否须明确（默认建议限制在单章节）。书籍内容被修改后，无法精确定位的记录需标记为失效或返回恢复失败状态，不得静默错标其他文字。

**FR-MARK-08 数据所有权**：宿主提供的书签/高亮初始数据不得被组件以隐藏副作用改写。组件交互产生的变更应通过明确回调/变更结果返回；组件不得把完整书籍正文或标注数据发送到网络。

### 4.4 分页与连续滚动

**FR-MODE-01 分页模式**：支持按可用正文宽高将章节拆成稳定顺序的多个页；一页可跨多个段落，一个段落也可跨多页。章节标题和正文按设置排版。

**FR-MODE-02 连续滚动模式**：正文区域纵向连续显示页面内容并可越过章节边界。当前视口所在章节及章节内页应可识别；滚动位置变化可通知宿主或内部进度显示。

**FR-MODE-03 相邻章节续接**：滚动到当前章前后边界时按需加载相邻章节；章节失败时在对应边界显示可重试状态。到达书籍首章或末章时不再请求越界章节。

**FR-MODE-04 模式切换锚定**：分页转滚动和滚动转分页均保持当前可见内容锚定。切换效果时，若从滚动模式退出，恢复到当前滚动视口对应章节和页。

**FR-MODE-05 滚动呈现特例**：连续滚动实现按内容流组织并复用章节片段，不要求每个滚动视口都被伪造为独立翻页动画的 Page。向前/向后加载章节、可见章节识别、进度映射和回分页锚定由滚动呈现实现负责；宿主仍通过共同导航与数据 API 获得标准化阅读位置。

### 4.5 翻页交互及动效

**FR-FLIP-01 手势翻页**：支持水平分页手势；当前实现还提供垂直无动画分页。手势方向、滑动阈值及动画时长应可由宿主或默认配置控制。点击不应误判为拖动。

**FR-FLIP-02 翻页结果**：手势结束后，根据拖动方向和距离决定提交翻页或复位到原页。手指拖动中页面应与手势保持连贯；反向拖动可取消原方向翻页。

**FR-FLIP-03 效果种类**：分页呈现至少提供无动画、覆盖、水平滑动、iBook 风格滑动、仿真卷页和 Google 风格卷页等预设视觉效果。连续滚动属于呈现方式，不列为普通翻页效果。若某效果存在平台/设备限制，应提供安全回退并保持导航语义一致。

**FR-FLIP-04 点击分区**：宿主可按触点在视图中的归一化位置处理点击，例如左侧上一页、右侧下一页、中间显示阅读菜单。区域回调可声明事件已消费，阻止普通点击回调继续执行；未消费时可交由常规点击监听器。

**FR-FLIP-05 程序翻页**：宿主可调用上一页/下一页导航触发翻页。可选择遵守最小翻页间隔或强制立即执行；边界检查始终有效。

**FR-FLIP-06 动画重入和中断**：连续触摸、快速程序翻页、切换效果或页面数据变更时，不得使页面停留在半翻状态、错页或出现残影。中断后应确定并公开最终阅读位置。

**FR-FLIP-07 效果/呈现兼容**：分页效果仅在兼容的分页呈现中生效。连续滚动使用呈现子类自身的垂直滚动行为；切换视觉效果不得隐式切换分页/滚动呈现。

**FR-FLIP-08 效果扩展 API**：宿主可提供自定义翻页效果实现。扩展能力须公开必要的输入（触点/手势进度、方向、视口尺寸、前后内容画面）、效果生命周期（开始、更新、提交、复位、中断、销毁）和完成结果；效果不得直接篡改阅读数据或绕过导航边界规则。自定义效果缺失/异常时可回退到无动画效果。

**FR-FLIP-09 默认效果配置**：组件提供预先实现的翻页效果，可由稳定的公开标识选择；效果配置可设置动画时长、触发阈值、速度限制等适用参数。效果种类、视觉表现与内容展示子类相互独立。

### 4.6 阅读样式与排版

**FR-STYLE-01 背景**：支持纯色、资源、Drawable/图片等背景表达；背景应用到阅读页面时不应改变书籍内容。

**FR-STYLE-02 字体**：标题和正文可分别指定字体、字号和颜色；页眉/页脚可配置文字颜色。字体配置改变后应触发必要的重新排版。

**FR-STYLE-03 间距**：分别支持阅读页、正文容器、正文内容、章节标题、页眉、页脚的四边内边距；支持段首缩进、标题/正文字符间距、正文行距和段距。

**FR-STYLE-04 标题对齐**：章节标题支持左对齐、居中和右对齐。

**FR-STYLE-05 主题**：示例 App 提供多种阅读主题，涵盖浅色/深色和不同背景样式。主题应协调背景与文字颜色，避免低对比度；主题数量及具体配色是示例 App 配置，不要求固化为阅读库的固定主题列表。

**FR-STYLE-06 排版后位置**：字号、字体、边距或间距变化导致页数和页界改变时，应重排当前相关内容并尽量恢复当前段落附近的位置；页码变化应同步更新。

**FR-STYLE-07 页眉/页脚定制**：宿主可隐藏/显示页眉页脚，设置其内容、位置、对齐、尺寸、字体、颜色、背景和四边 padding，或提供自定义视图/内容渲染。自定义不应破坏正文可用视口计算。

**FR-STYLE-08 页面内容定制**：子类/宿主可决定页面中标题、正文、图片、章节信息、进度等内容如何组合与绘制。组件必须提供足够的内容和位置上下文，不要求使用默认阅读页布局。

**FR-STYLE-09 完整间距配置**：对页面、内容视口、正文、标题、页眉、页脚以及适用的段落/图片分别提供可读写的 padding/spacing 配置。单位及方向约定需一致，水平布局需支持左右方向语义。

### 4.7 示例 App 功能

**FR-DEMO-01 体验入口**：示例首页提供阅读器演示、从系统文件选择器选取文件、网络加载演示及独立翻页/容器效果演示入口。开发测试用的图形实验页仅作内部调试，不作为正式读者功能要求。

**FR-DEMO-02 阅读控制面板**：阅读页点击中间区域可显示/隐藏控制面板。面板提供目录、排版设置、阅读设置、上一章/下一章和章节进度跳转。

**FR-DEMO-03 目录面板**：展示章节标题列表，选择章节后跳转到该章节；目录不可用或尚未准备完成时，不应提供会失败的伪可用操作。

**FR-DEMO-04 排版面板**：示例界面允许调整页面/页眉/页脚/正文/标题/正文内容的边距；标题与正文字号；标题与正文字符间距；正文行距和段距；章节标题对齐。

**FR-DEMO-05 阅读设置面板**：示例界面允许切换支持的翻页效果和阅读主题。

**FR-DEMO-06 退出**：页眉退出控件可由宿主接管；示例应用退出当前阅读界面时可由宿主选择保存进度等动作。库本身不承担进度持久化。

**FR-DEMO-07 组件 API 展示**：Demo 至少展示一种宿主数据源接入、一种阅读进度恢复、一组书签/高亮导入导出、页面内容定制和自定义翻页效果接入流程，便于集成方验证组件扩展面。

## 5. 质量属性与验收目标

本节定义新实现必须满足的质量结果。具体设备基准和量化阈值需在实现阶段以目标设备矩阵确认；在确认之前不得声称已达到某个帧率、内存或冷启动数字。

### 5.1 性能与流畅度

- 页面翻动期间不得在主交互路径上同步读取完整远程章节、解析整本书或执行大规模分页。
- 当前章应优先可读；邻章准备应在可见前完成，缓慢来源不能冻结触摸和页面响应。
- 翻页过程画面连续，无明显跳帧、闪白、页面空洞或相邻页缝隙；动画结束后绘制结果与最终阅读位置一致。
- 页面缓存和预加载占用应随视口邻近范围受控，而不随已阅读总页数无界增长。
- 大章节分页与重新排版应可取消过时任务；旧样式、旧尺寸的计算结果不得覆盖新状态。
- 验收应覆盖低端目标机、常见中端机和高刷新率设备；量化帧时间、首次显示时间、翻页响应、内存峰值和长时间阅读后的资源趋势。

### 5.2 稳定性与恢复

- 设备旋转、窗口尺寸改变、App 前后台切换和阅读效果切换后，不崩溃、不重复提交页码变化、不显示错误章节。
- 动画期间收到取消、数据更新或视图销毁时，渲染资源可释放，阅读位置保持一致。
- 来源错误、空文件、无章节文件、编码问题和部分章节加载失败均有可恢复状态。

### 5.3 可访问性与输入

- 正文和交互控件可通过 Android 无障碍服务识别；点击/触控区域外，仍应存在可被辅助技术触发的上一页、下一页、目录和设置操作。
- 不应只依赖颜色表示加载、错误或选中状态。
- 系统字体缩放、深色模式、屏幕阅读器及触控目标尺寸应纳入验证。
- 如支持减少动态效果偏好，仿真动画应能退化为较短或无动画切换，同时保留阅读导航功能。

### 5.4 兼容性与数据安全

- 文件访问遵循 Android 用户授权的 URI/文件访问能力；取消选择不应创建错误阅读会话。
- 阅读库不得擅自上传书籍文本、阅读位置或用户配置。
- 文本来源和网络来源由宿主管理权限、认证和错误重试策略；示例网络服务不构成生产可靠性保证。

## 6. 关键状态和一致性规则

不规定状态在内部如何表示，但外部行为须遵守以下规则：

1. 阅读会话从未打开、目录准备、章节准备、可读、失败/可恢复到关闭，状态变化可被宿主观察。
2. 翻页手势只能产生一个最终结果：提交下一页、提交上一页、或取消并回原页。
3. 阅读位置是内容位置，不等同于动画偏移。动画开始不提前发布新位置；提交时只发布一次位置变更。
4. 排版配置变化会使旧分页失效；旧任务的结果不能污染新配置的页面。
5. 当前页、章节内页、全书页和滚动锚点之间可相互转换，且切换模式时保留当前阅读内容。
6. 加载重试应与旧请求隔离；旧请求迟到返回不能覆盖较新的书籍/章节会话。
7. 书籍替换后，前一本书的异步内容、缓存、回调和动画不得再影响新书。
8. 自定义内容子类不得绕开数据所有权、导航边界、标注锚点和状态通知规则。
9. 书签与高亮存储由宿主掌控；组件负责解析/展示/交互和输出变更，不要求宿主使用组件内部数据存储。

## 8. 验收场景

以下场景均应通过人工或自动验收；实现时应扩展为测试用例。

1. 使用无章节标题的文本打开书籍，开头内容仍可读；能正常创建可导航章节。
2. 使用自定义标题规则打开文本，目录标题及章节顺序与来源一致。
3. 打开指定章节及页；无效章节/页返回失败并按约定回退，不崩溃。
4. 从中间页连续向前/向后翻页，页码与实际内容一致；手势取消时仍停留在原页。
5. 在首尾页执行手势、点击和程序导航，均不越界；从章节末页正常翻入下一章，反向亦然。
6. 在动画中快速反向拖动、连续点击翻页、切换效果或触发页面尺寸变化，最终页与回调一致，无卡页或残影。
7. 每一种翻页效果都能完成拖动、程序翻页、边界处理、动画中断和效果切换；卷页在不同设备尺寸下绘制完整。
8. 在线来源加载慢时当前章节仍可响应；相邻章节预加载成功可无缝切换，失败可重试且不丢当前位置。
9. 更改字号、字体、边距和背景后内容正确重排，位置尽可能锚定；页数和页码同步更新。
10. 滚动阅读跨越两章后切回分页，落在滚动视口对应内容；从分页切入滚动亦不跳页。
11. 旋转/调整窗口后分页更新，当前阅读内容尽量保持；加载与动画状态不会重复提交或错乱。
12. 替换书籍或关闭阅读页后，旧章节任务和旧页面不再出现在新书中，临时渲染资源释放。
13. 示例 App 可完成本地文件选择、取消选择、目录跳转、主题切换、排版控制、翻页模式切换和退出阅读。
14. 空文件、解析失败、目录失败和单章失败有清晰提示与可执行恢复路径。
15. 阅读 Widget 能从 XML 与代码创建，在普通宿主布局中测量/显示；同页两个实例的状态、来源与效果互不干扰。
16. 宿主提供书签/高亮，交互产生增删改输出；重新排版/切换模式后锚点保持，失效标注不得错落到其他文字。
17. 宿主通过页面模板、内容呈现和效果公开扩展接口完成定制，Demo 不引用内部协调器或内部页对象。
18. 全书页数尚未计算时明确显示未知；显式构建完整页索引可取消，内容/版式更新使旧索引失效。
19. 快速换书、章节更新、视图离开窗口时，旧任务不得提交内容；重新挂载和宿主重建后能按来源及轻量位置恢复。
20. Java/非协程请求能取消，每个请求恰好完成一次；加载中、边界与不支持操作均有明确结果。

## 9. 明确不规定的实现事项

后续重构可以替换现有 ViewGroup、Adapter、渲染器、线程/任务机制、分页算法或 UI 框架。不得把当前包结构、类名、继承层级、三页缓存策略、Canvas/OpenGL 选择或现有效果数学公式视为需求。唯一约束是保持第 4 节的功能行为与第 5、6、8 节的质量和一致性要求，或经明确产品决策记录兼容性变更。

## 10. 待产品确认项

这些问题会改变新项目的范围；本需求基线暂不擅自扩张：

1. **双页模式**：平板/横屏是否必须支持一屏双页？当前库主要按单页导航实现，实验视图不等同于正式能力。
2. **图片与 EPUB 完整度**：是否要求图片、章节内样式、目录层级、脚注等完整 EPUB 内容？当前 EPUB Loader 只是文本提取。
3. **标注范围**：本项目目标已包含选词、书签/高亮输入输出及重新分页锚定；同章跨段落、跨章节选择及笔记的具体范围仍需确认。API 草案建议同章跨段落，首版限制跨章节。
4. **可选存储适配**：默认由宿主保存阅读位置/标注，库提供输入、输出、轻量快照与恢复契约；是否另外提供可选本地存储适配器？
5. **设备覆盖**：交付形态已确定为 Android View Widget；平板/折叠屏/多窗口的验收设备范围仍需明确。Compose 可包装 View，是否提供专用包装模块待定。
6. **性能验收设备与阈值**：目标 Android 最低版本、设备档位、动画帧时间、打开首屏时间、内存峰值及书籍规模上限。
7. **效果范围**：Google 风格卷页和 iBook 风格卷页是否都必须保留，还是可用一个更稳定的卷页实现替代其中之一？当前 README 公开两者，但 Demo 设置 UI 未包含 Google Curl。
8. **触控与无障碍**：阅读点击分区、音量键翻页、外接键盘/遥控器及屏幕阅读器操作需覆盖到什么程度？

建议在开始重构前确认这些产品选项，并将确定结果记录为本文件的决策补充；其余章节可作为当前功能等价重做的需求基线。
